# Mini Gestor de Contactos - Elys

## Descripción
Este proyecto es un **Mini Gestor de Contactos** desarrollado en **Python con Flask**, que permite realizar operaciones **CRUD** (Crear, Leer, Actualizar, Eliminar) sobre contactos.  
Además, se implementaron **pruebas automatizadas con Selenium**, incluyendo capturas automáticas de cada escenario.

---

## Contenido del repositorio
- `app.py` - Aplicación principal en Flask.
- `templates/` - Plantillas HTML (`index.html`, `create.html`, `edit.html`).
- `data.json` - Archivo JSON donde se guardan los contactos.
- `test_automation.py` - Script de pruebas automatizadas con Selenium.
- `screenshots/` - Capturas automáticas de los escenarios de prueba.
- `reporte.html` - Reporte de las pruebas automatizadas.
- `chromedriver.exe` - Driver de Chrome necesario para Selenium.

---
